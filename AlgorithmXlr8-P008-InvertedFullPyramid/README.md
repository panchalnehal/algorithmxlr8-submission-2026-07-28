# Inverted Full Pyramid

**Difficulty:** `Easy`

## Problem

Given a non-negative integer n, print an inverted centered pyramid of stars: n rows, where row i (1-indexed) contains (2*(n - i + 1) - 1) stars, centered using (i - 1) leading spaces.

Read n from standard input. Print n lines. If n is 0, print nothing.

## Examples

### Example 1

**Input**
```
n = 4
```
**Output**
```
*******
 *****
  ***
   *
```

**Explanation:** Row 1 has no leading spaces and 7 stars; row 4 has 3 leading spaces and 1 star.

### Example 2

**Input**
```
n = 1
```
**Output**
```
*
```

**Explanation:** A single row with a single star.

### Example 3

**Input**
```
n = 2
```
**Output**
```
***
 *
```

**Explanation:** Row 1 has no leading spaces and 3 stars; row 2 has 1 leading space and 1 star.
